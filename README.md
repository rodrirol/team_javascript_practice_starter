# Team JavaScript Practice

Each student completes one card on the page by writing code in one JavaScript file.

| Student | Level | File | Card |
| --- | --- | --- | --- |
| 1 | Beginner | `js/student1.js` | Temperature Converter |
| 2 | Beginner | `js/student2.js` | Favorite Color |
| 3 | Beginner | `js/student3.js` | Age in Months and Days |
| 4 | Intermediate | `js/student4.js` | Grade Checker |
| 5 | Intermediate | `js/student5.js` | Piggy Bank |
| 6 | Advanced | `js/student6.js` | Shopping List |

## How to work

1. Clone the repository and open `index.html` in your browser.
2. Open your JavaScript file and follow the steps in its comments.
3. Save your file and reload the page to test your work. The end of your file has a checklist.
4. If something does not work, open the browser console (F12) to look for errors.

## Using GitHub

Get the latest changes before you start:

```
git pull
```

When your work is ready, add **only your own file** (this example is for Student 1):

```
git add js/student1.js
git commit -m "Complete temperature converter"
git pull
git push
```

Do not edit `index.html`, `style.css`, or another student's file. That way, you will not get merge conflicts.
